# ChEMBL37 extraction and curation scope

Repository Table S3 archives the 3,283 ChEMBL-derived rows that were subjected to the normal-like assay curation audit: 166 accepted rows and 3,117 excluded/ambiguous rows. The curation audit is reproducible from these archived rows, the accepted/excluded CSV files, and `curation_rules.csv`.

The lightweight bundled repository does not execute a live ChEMBL SQL/API extraction, and the exact upstream SQL, API, or web-interface query parameters used to derive the 3,283-row ChEMBL37 extraction set were not retained in this repository. Therefore, the live upstream extraction from ChEMBL37 should be treated as a provenance step recorded by the archived 3,283-row audit set rather than as a query regenerated by `analysis/run_all.py` or `analysis/validate_repository.py`.

The inclusion audit used the following retained fields, where available: compound name, ChEMBL molecule identifiers, assay description, assay type, BAO format/label, endpoint type, activity relation/value/units, organism, target name, target organism, document identifiers, and source descriptions. Curation then used `curation_rules.csv` to classify rows as accepted normal-like/non-cancer-like viability/cytotoxicity evidence or as excluded/ambiguous rows.

Interpretation: S3 supports reproducibility of the curation and exclusion audit from the archived 3,283-row extraction set. It does not by itself guarantee live re-extraction of the same 3,283 rows from ChEMBL37 without the original external query environment.
