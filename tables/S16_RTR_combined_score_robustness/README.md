# Repository Table S16: RTR combined-score robustness outputs

This folder contains the manuscript-supporting robustness outputs for the combined RTR score.

Files:

- `RTR_secondary_primary_rank_concordance.csv`: concordance between Secondary and Primary RTR percentile-rank components across dual-evaluable cell lines.
- `RTR_top100_primary_only_enrichment.csv`: Primary-only enrichment in the default combined Top100 set.
- `RTR_dual_evaluable_top100_lineage_enrichment.csv`: Bone+Soft Tissue lineage-enrichment sensitivity in the dual-evaluable-only Top100 set.

These files are copied from `outputs/tables/` so that the S-numbered repository-table deliverable is self-contained.
