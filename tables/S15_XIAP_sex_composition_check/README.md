# Repository Table S15: XIAP sex-composition check

This folder contains the XIAP sex-composition check used to evaluate whether the RTR top-versus-bottom `XIAP` dependency signal could be explained by sex-composition imbalance.

Files:

- `S15_XIAP_sex_composition_check_summary.csv`: group-level Fisher exact, chi-square, sex-adjusted OLS, and sex-stratified summaries.
- `S15_XIAP_sex_composition_check_per_cellline.csv`: per-cell-line RTR group, lineage, sex, and XIAP dependency-score records used by the check.

These outputs are regenerated by `analysis/14_verify_xiap_sex_composition_check.py` when the required raw inputs are available.
