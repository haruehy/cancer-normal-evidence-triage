# Normal Protection Evidence Literature v1

This package collects literature-based normal protection evidence for the four repair/protection candidates:
Trolox, Taurine, Benfotiamine, and L-ergothioneine.

This is a PN-prior table only. It does not prove cancer-vs-normal selectivity and does not prove that repair+removal-axis improves separation.
The correct use is to prioritize direct fourth-paper assays:
control, repair only, removal-axis only, repair+removal-axis, in both normal-like and RTR-high cancer models.

Key interpretation:
- Trolox and L-ergothioneine have the strongest direct normal-like cell protection evidence.
- Taurine has moderate supportive evidence but less direct human-normal-cell evidence.
- Benfotiamine has a vascular/metabolic protection rationale but mixed clinical biomarker evidence.


## Scoring note for PN prior

PN values were rescaled from a maximum of 7 points. Component categories could receive fractional values within their allowed ranges when evidence was intermediate. Caveat subtraction was applied as a fractional adjustment up to 1 point, with 0, 0.5, and 1.0 used as anchor values rather than the only possible totals. Thus values such as Trolox PN=0.80 reflect fractional component totals after caveat adjustment.
