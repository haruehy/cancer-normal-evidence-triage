# Input data directory

Place public input datasets here using the filenames defined in `analysis/config.py` and documented in `tables/S14_input_file_provenance_manifest.csv`.

## Fixed curated manuscript annotation

`curated_compound_annotations.csv` is included in this package and is the source of truth for the manuscript compound categories. It fixes the final counts used in the paper:

- strict repair/protective: 6
- broad repair/protective: 75
- cytotoxic/removal-like: 157
- other: 1261

The script `analysis/01_build_compound_annotations.py` reads this fixed table instead of re-generating categories from keyword or regular-expression rules. Regular-expression rules are used only for optional descriptive subclass and removal-axis labels when absent; they do not change `analysis_group`.

## Large public datasets not bundled

Large source files such as PRISM, DepMap CRISPR, mutation calls, and NCI-ALMANAC should be downloaded from their public sources and placed in this directory before running the full pipeline.

## Archived intermediate tables (bundled, manuscript values)

Two per-cell-line intermediates are bundled so that the published statistics
and figure-source values can be reproduced without first re-deriving them
from the very large raw PRISM/DepMap matrices:

- `RTR_combined_decomposition_578.csv` — combined PRISM Secondary + Primary RTR
  decomposition over the n=578 evaluable cell lines (480 in both screens + 98
  Primary-only). Read by `analysis/04_rtr_score_decomposition.py`. Reproduces
  Spearman rho = 0.361 (repair-preservation) and 0.679 (removal-vulnerability).
- `TP53_interaction_recovered.csv` — refined TP53 interaction results
  (Secondary and Primary; value-level OLS + cell-line-level delta). Read by
  `analysis/05_tp53_interaction_tests.py`. Reproduces the cell-line delta
  results p = 0.242 (Secondary, n=469) and p = 0.276 (Primary, n=565).

To rebuild these intermediates from scratch (instead of using the bundled
copies), the following large public files must be downloaded into this folder:

- `secondary-screen-dose-response-curve-parameters.csv` (PRISM Secondary)
- `primary-screen-replicate-collapsed-logfold-change.csv` (PRISM Primary matrix)
- `primary-screen-replicate-collapsed-treatment-info.csv` (PRISM Primary metadata)
- `OmicsSomaticMutations.csv` (DepMap; required for TP53 refined status)
- `CRISPRGeneEffect.csv` and `Model.csv` (DepMap; required for the CRISPR
  dependency re-screen, including the ATM and XIAP candidate genes)

Note on ATM/XIAP reproducibility:

`outputs/tables/lineage_adjusted_dependency_regression.csv` includes ATM and
XIAP rows, generated by running `analysis/06_depmap_crispr_rescreen.py`
against the raw DepMap Public 26Q1 `CRISPRGeneEffect.csv` and `Model.csv`.

ATM, `repair_high_removal_high_vs_others` comparison: lineage-adjusted OLS
p = 0.0188, FDR = 0.150 (nominally significant before FDR correction, not
significant after candidate-level FDR correction). The manuscript (Section
4.10) reports this same value, p = 0.0188, consistent with this bundled
table. This table is consistent with the manuscript value reported in
Section 4.10.
