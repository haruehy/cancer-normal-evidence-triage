# Figure files and source tables

The manuscript submits Figures 1--5 as separate figure files. The bundled repository does not regenerate final figure artwork. The table `outputs/tables/figure_source_map.csv` records the processed repository outputs that support each figure caption or panel-level value so that figure content can be traced back to manuscript-supporting tables.

This directory is intentionally documentation-only in the bundled repository. Final figure image/PDF/EPS files should be uploaded separately in the journal submission system.
